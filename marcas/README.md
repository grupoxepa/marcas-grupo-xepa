# Marcas do Grupo XEPA — assets e tokens

Uma pasta por marca, com logos, KVs, imagens, fontes e `tokens.css` (cores + fontes prontas para usar em CSS).
As regras de uso de cada marca estão nas skills do Claude Code em `.claude/skills/`:

| Marca | Pasta | Skill |
|---|---|---|
| Grupo XEPA (marca-mãe) | `marcas/grupo-xepa/` | `/kv-grupo-xepa` |
| XEPA | `marcas/xepa/` | `/kv-xepa` |
| Ó Pro Cê Vê (OPCV) | `marcas/opcv/` | `/kv-opcv` |
| Xodó | `marcas/xodo/` | `/kv-xodo` |

Arquivos de trabalho (PSD editável do OPCV) e a fonte Oferta do Dia não estão neste repositório público; peça ao Grupo XEPA.
