# Marcas do Grupo XEPA

Identidade visual (KV) do **Grupo XEPA** e das suas casas — **XEPA**, **Ó Pro Cê Vê (OPCV)** e **Xodó** — para quem cria peças, sites e sistemas para o grupo.

- `marcas/<marca>/` — logos, KVs, ilustrações, fotos e `tokens.css` (cores e fontes prontas para CSS).
- `.claude/skills/` — skills do Claude Code com as regras de cada marca: `/kv-grupo-xepa`, `/kv-xepa`, `/kv-opcv`, `/kv-xodo`.

Para usar as skills: clone este repositório (ou copie `.claude/skills` para o seu projeto) e rode o Claude Code na pasta.
